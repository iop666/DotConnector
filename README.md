# 🖱️ DotConnector 连点器

轻量、可靠的 Windows 鼠标连点工具。**纯 Python + tkinter** 实现，通过 `ctypes` 直接调用 Win32 `mouse_event` / `SetCursorPos` 模拟点击，**零第三方运行时依赖**。

---

## ✨ 特性一览

- 🖱️ 支持**左键 / 中键 / 右键**
- ⏱️ 三种点击模式：**固定间隔 / 随机间隔（可设范围）/ 长按模式**
- 🚀 5 个常用速度预设：1 秒 1 / 10 / 20 / 50 / 100 下
- 📍 点击位置：**跟随鼠标** 或 **锁定坐标**（快捷键捕获 / 手动输入，可 ±5px 随机偏移）
- ⏹️ 三种停止条件：**点击次数 / 倒计时 / 运行到指定时刻**（三选一互斥）
- 🪟 窗口检测：按**窗口标题或进程名**匹配，目标失焦自动暂停、切回自动恢复
- ⌨️ 三个**全局热键**（窗口不在前台也响应），支持自定义
- 📊 详细**运行日志**：开始/停止/暂停全记录 + **点击坐标统计**，支持导出 MD / TXT
- 🎨 v2 风格 Fluent 界面：顶部标签页布局 + 自绘现代单选/复选控件
- 📌 置顶实时计数小窗、系统托盘红/绿运行状态、界面 100/150/200% 缩放
- 💾 配置自动保存到 `config.ini`，重启自动恢复

## 🚀 快速上手

<img width="990" height="995" alt="image" src="https://github.com/user-attachments/assets/fb09d459-0950-4bcb-ba4a-05255cc46557" />

1. **打开软件**，默认显示「点击设置」页
2. 选择 **点击模式**（如固定间隔）、**鼠标按键**（默认左键）
3. 设置 **点击速度**（如间隔 100ms → ≈ 每秒 10 次，或点预设按钮）
4. 设置 **点击位置**（默认跟随鼠标；或选锁定坐标，按 `Ctrl+Shift+F8` 捕获当前坐标）
5. （可选）勾选 **停止条件**（次数 / 倒计时 / 运行到点）
6. 按 **`Ctrl+F9`** 启动连点，再按一次停止

## ⚙️ 功能详解

### 点击模式

| 模式 | 说明 |
|---|---|
| **固定间隔** | 每次点击间隔相同（1–2000ms），常用预设可用 |
| **随机间隔** | 每次间隔在「最小~最大」间随机（最小>最大自动交换），预设按钮自动禁用 |
| **长按模式** | 按住指定时长后松开，循环执行（可设按住/松开时间），预设按钮自动禁用 |

### 点击速度

- 输入毫秒间隔，右侧**实时换算**「≈ 每秒 X 次」
- 预设按钮：`1秒1下`(1000ms) · `1秒10下`(100ms) · `1秒20下`(50ms) · `1秒50下`(20ms) · `1秒100下`(10ms)

### 点击位置

| 策略 | 说明 |
|---|---|
| **跟随鼠标** | 鼠标指针在哪里就在哪里点击 |
| **锁定坐标** | 始终点击固定坐标（捕获/手输），可开 ±5px 随机偏移避免过度精确 |

### 停止条件

点击次数 / 倒计时（分+秒）/ 运行到指定时刻（时:分:秒，到点自动停止）——**三选一互斥**。

### 窗口检测

- 勾选后仅当目标窗口处于活动状态时才连点，失焦自动暂停、切回自动恢复
- 按**窗口标题**或**进程名**匹配；点「选择运行中的程序…」可视化选择
- ⚠️ 窗口检测开启但**未选择窗口**时启动，会弹出提示并阻止运行

### 运行日志

- 记录：程序启动、开始连点（含完整配置）、停止（次数/耗时/原因）、窗口暂停/恢复、坐标捕获、热键修改
- **点击坐标统计**：停止时输出 `点击坐标: (400,200) × 15 次`（多坐标按次数降序取前 5）
- 支持**导出 MD / TXT** 到任意位置

## 🛡️ 安全与稳定性

- 点击引擎**独立线程**运行，手动停止 **0.1 秒内响应**
- 长跑**内存零增长**（实测 8 秒高频点击零泄漏，常驻约 25MB）
- 配置**退出自动保存**，崩溃不丢设置
- 强制退出热键 `Ctrl+Alt+F10` 用于失控应急

```bash

    --icon icon.ico --add-data "icon.ico;." DotConnector_basic.py
```

### 架构说明

```
ClickEngine（独立线程）
    ├─ 固定间隔/随机/长按三种节奏
    ├─ ctypes → user32.mouse_event 模拟点击
    └─ 坐标记录（coord_counts / last_coord）

Tray（独立线程）
    ├─ RegisterHotKey 全局热键
    ├─ 系统托盘图标（红/绿状态）
    └─ 消息循环转发给主线程

主线程（tkinter UI）
    ├─ 顶部标签页 + 自绘 ModernRadio/ModernCheck
    ├─ config.ini 持久化
    └─ 运行日志（内存 + logs/dotconnector.log 文件）
```

## ❓ 常见问题

**Q：软件被安全软件告警？**
模拟点击类工具可能被个别安全软件标记，属正常现象；本工具仅调用系统标准 API，不含恶意行为。

**Q：热键没反应？**
检查是否有旧实例残留占用全局热键（任务管理器结束所有 `DotConnector.exe` 再启动）。

**Q：高 DPI 下界面模糊/溢出？**
程序已开启 DPI 感知，建议「界面设置」中将缩放设为 200%（高 DPI 系统默认）。

**Q：想连点但不想误触？**
推荐勾选窗口检测并绑定目标窗口，失焦自动暂停。
